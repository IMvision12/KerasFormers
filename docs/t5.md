Google's original **T5** (Text-to-Text Transfer Transformer) in **pure Keras 3**: the
encoder-decoder transformer with relative position bias, T5-style RMSNorm, and the full
head set (conditional generation, encoder-only, sequence / token classification, and
question answering). One implementation runs unmodified on **TensorFlow / Torch / JAX**,
bit-exact with Hugging Face on real checkpoints (see below).

**Paper**: [Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer](https://arxiv.org/abs/1910.10683)

This port targets **original T5** (`t5-small` / `base` / `large` / `3b` / `11b`): a
ReLU `dense-relu-dense` MLP, a shared token embedding, and an LM head **tied** to that
embedding with the decoder output scaled by `embed_dim ** -0.5`. (v1.1 / Flan-T5, which
use gated-GELU and an untied head, are not covered.)

All classes live in `kerasformers.models.t5` and are imperative
`SubclassedBaseModel`s; the heads extend the backbone.

| Task | Class | HF equivalent | Output |
|---|---|---|---|
| Backbone | `T5Model` | `T5Model` | `{"last_hidden_state": (B, T, d), "encoder_last_hidden_state": (B, S, d)}` |
| Generation | `T5ConditionalGenerate` | `T5ForConditionalGeneration` | `{"logits": (B, T, vocab), ...}` + `.generate()` |
| Encoder only | `T5EncoderModel` | `T5EncoderModel` | `{"last_hidden_state": (B, S, d)}` |
| Sequence classify | `T5SequenceClassify` | `T5ForSequenceClassification` | `(B, num_classes)` |
| Token classify | `T5TokenClassify` | `T5ForTokenClassification` | `(B, S, num_classes)` |
| Question answering | `T5QnA` | `T5ForQuestionAnswering` | `{"start_logits": (B, T), "end_logits": (B, T)}` |
| Tokenizer | `T5Tokenizer` | `T5TokenizerFast` | `input_ids` / `attention_mask` |

The one hosted `model.weights.h5` (declaring `T5Model`) is the full encoder-decoder; every
class loads its own subset via `CHECKPOINT_SOURCE` (`T5ConditionalGenerate` ties the LM head, so it
adds no weight; the classification / QA heads are randomly initialized, ready for
fine-tuning, and load trained weights from a `hf:` fine-tune).

## Loading

```python
from kerasformers.models.t5 import T5ConditionalGenerate, T5Tokenizer

model = T5ConditionalGenerate.from_weights("kerasformers/t5_base")
tokenizer = T5Tokenizer.from_weights("kerasformers/t5_base")
```

Or convert on the fly from the upstream checkpoint with `from_weights("hf:google-t5/t5-base")`.

## Text-to-text generation

```python
inputs = tokenizer("translate English to German: The house is wonderful.")
output_ids = model.generate(inputs["input_ids"], inputs["attention_mask"], max_new_tokens=40)
print(tokenizer.decode(output_ids[0]))  # "Das Haus ist wunderbar."
```

`generate` runs the encoder once and greedily decodes, cross-attending to the frozen
encoder output at each step.

## Encoder features

```python
from kerasformers.models.t5 import T5EncoderModel

encoder = T5EncoderModel.from_weights("kerasformers/t5_base")
feats = encoder(tokenizer("The quick brown fox."))["last_hidden_state"]  # (1, S, 768)
```

## Scoring a target sequence

```python
from kerasformers.models.t5 import T5Model

model = T5Model.from_weights("kerasformers/t5_base")
out = model({
    "input_ids": inputs["input_ids"],
    "attention_mask": inputs["attention_mask"],
    "decoder_input_ids": decoder_ids,   # right-shifted targets; omit to shift input_ids
})
out["last_hidden_state"]  # decoder states (B, T, d)
```

## Architecture notes

- **Relative position bias**, not absolute or rotary: a learned
  `Embedding(num_buckets, num_heads)` per stack, bucketed by `memory - query`
  (bidirectional in the encoder, causal in the decoder) and shared across all layers of
  that stack. Cross-attention uses no relative bias.
- **T5LayerNorm** is RMSNorm (scale only, no mean subtraction, no bias). Residuals are
  **pre-LayerNorm** (`x + Sublayer(LayerNorm(x))`), and each stack ends with a final RMSNorm.
- **No `1/sqrt(d)` attention scaling** and **no biases** in the q/k/v/o or MLP projections.
  The attention inner dimension is `num_heads * key_value_dim`, which may differ from
  `embed_dim` (e.g. `t5-3b`).
- The decoder starts from the **pad token** (`decoder_start_token_id = pad_token_id = 0`)
  and the LM head is the transposed shared embedding, scaled by `embed_dim ** -0.5`.

## Parity

Bit-exact with Hugging Face `transformers` (eager, float32): `T5ConditionalGenerate` logits and the
`T5EncoderModel` last hidden state match to `0.0` max-abs difference; the classification
and QA heads match to `< 2e-7`. See `convert_t5_hf_to_keras.py` for the reference
conversion and its parity gate.
